# Decode_Labs_Internship_Tasks



A collection of 4 industrial AI projects completed as part of DecodeLabs internship training program, covering the full spectrum from rule-based logic to neural networks.

---

## 📁 Project Structure

| Project | Topic | Key Tech |
|---------|-------|----------|
| Project 1 | Rule-Based AI Chatbot | Python, Dictionaries, Control Flow |
| Project 2 | Data Classification (KNN) | Scikit-learn, KNN, Confusion Matrix |
| Project 3 | AI Recommendation System | TF-IDF, Cosine Similarity, NumPy |
| Project 4 | Neural Network from Scratch | NumPy, Backpropagation, Sigmoid |

---

## 🚀 Projects Overview

### Project 1 — Rule-Based AI Chatbot
A keyword-based chatbot using dictionary lookup (O(1)) instead of if-elif ladder (O(n)). Handles greetings, AI questions, and unknown inputs with a fallback response.

### Project 2 — Data Classification Using KNN
Supervised learning pipeline on the Iris dataset. Includes feature scaling, train-test split, KNN classifier, confusion matrix, and F1 score evaluation.

### Project 3 — AI Recommendation System
Content-based filtering engine that maps user skills to job roles using TF-IDF vectorization and cosine similarity. Returns Top 3 ranked career matches.

### Project 4 — Neural Network from Scratch
A 2-layer neural network built using only NumPy. Trained on the XOR problem using forward propagation, sigmoid activation, and backpropagation weight updates.
